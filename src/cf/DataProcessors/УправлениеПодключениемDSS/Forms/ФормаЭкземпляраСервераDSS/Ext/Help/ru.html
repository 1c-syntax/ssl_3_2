Предназначена для хранения настроек подключения к сервису DSS.

Сервис DSS позволяет хранить сертификаты и закрытые ключи к ним. Это позволяет пользователю использовать функции подписания, шифрования, расшифровки данных практически с любого компьютера. Для использования этого функционала не требуется установки криптопровайдеров и сертификатов на локальный компьютер, достаточно предоставить данные для авторизации на настроенном сервисе.

К каждому серверу DSS привязываются учетные записи этого сервиса, указываемые в справочнике «Учетные записи DSS».

Форма создания сервера DSS содержит вкладку Основное, а также ссылки Расширенные настройки, Обсуждение и другие действия. 

Основное (настройка подключения)

  • В поле Адрес сервера указывается полный веб-адрес подключения к сервису (например, https://dss.cryptopro.ru).
  • В поле Адрес сервиса центра идентификации указывается полный или относительный адрес подключения (например, "STS").
  • В поле Адрес сервиса электронной подписи указывается полный или относительный адрес подключения (например, "SignServ...").
  • В поле Адрес сервиса проверки подписи и сертификатов указывается относительный или полный адрес.
  • В поле Адрес личного кабинета указывается полный или относительный адрес подключения. Это поле является не обязательным, информация в нём может быть удобной для организации быстрого перехода к странице личного кабинета пользователя, опубликованного на сервисе.
  • В поле Идентификатор OAuth клиента указываются ключевые данные для идентификации пользователя при авторизации через OAuth.
  • В поле Секрет OAuth клиента указывается секретный ключ для OAuth авторизации.
  • В поле Комментарий можно ввести дополнительное описание о сервере.

Расширенные настройки

По кнопке Расширенные настройки можно перейти на отдельную форму для указания необязательных настроек.

Вкладки расширенных настроек

Форма расширенных настроек содержит три вкладки: Прочие, Первичная авторизация, Вторичная авторизация. Доступна также кнопка Продолжить для последовательной настройки.

Прочие

  • Представление — настройка отображения сервера в списках (может быть задано вручную или формироваться автоматически).
  • Таймаут (сек.) — время ожидания подключения к сервису в секундах (по умолчанию 120).
  • Шаблон подтверждения — шаблон для формирования подтверждения операций (подробнее — по ссылке с символом [i]).
  • Версия API — версия поддерживаемого API для взаимодействия с сервером (например, 2.0.2882).
  • Используется — флажок, указывающий, что данный сервер активен и может использоваться. При отключении флажка сервер исключается из последующего создания учетных записей и выбора учетных записей.

Настройки авторизации

На вкладках Первичная авторизация и Вторичная авторизация можно настроить способы авторизации на сервере DSS.

Способы авторизации ограничены списком. По умолчанию доступны все способы авторизации.

Доступные способы авторизации:

  • Логин и пароль — стандартная авторизация с использованием учётной записи.
  • Логин и пароль с дополнительным подтверждением — двухфакторная авторизация.
  • Сертификат авторизации — авторизация с использованием сертификата электронной подписи.
  • Авторизация через Web-форму — авторизация через веб-интерфейс.
  • Сервисный клиент — авторизация для сервисных учётных записей.

Способы вторичной авторизации (подтверждения операций):

  • Мобильное приложение myDSS — подтверждение через мобильное приложение myDSS.
  • Электронная почта — подтверждение через электронную почту.
  • SMS — подтверждение через SMS-сообщение.
  • Мобильное приложение AirKey DSS — подтверждение через мобильное приложение AirKey DSS.
  • Мобильное приложение myDSS 2.0 или другое — подтверждение через другие мобильные приложения.
