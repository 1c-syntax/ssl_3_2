Предназначен для просмотра списка всех зарегистрированных серверов DSS.

В списке выводится:

  • Наименование - полное наименование сервера DSS;
  • Адрес сервера – содержит web-адрес подключения к серверу DSS;
  • Комментарий – дополнительное описание сервера.

Добавление сервера

  • Нажмите Добавить.

Просмотр данных о сервере

  • С помощью команды Изменить контекстного меню по правой кнопке мыши или меню Еще можно открыть данные о сервере DSS.
