Предназначена для смены пин-кода доступа к закрытому ключу сертификата, хранящегося в сервисе DSS.

Смена пин-кода

  • В поле Текущий пин-код необходимо ввести действующий пин-код доступа к закрытому ключу сертификата.
  • В поле Новый пин-код необходимо ввести новый пин-код, который будет установлен для сертификата.
  • В поле Подтверждение необходимо повторно ввести новый пин-код для подтверждения правильности ввода.
  • Флажок Сохранить позволяет сохранить новый пин-код в базе данных. В этом случае при последующих операциях пин-код не будет запрашиваться, а приложение сразу будет использовать сохраненный пин-код для доступа к сертификату.
  • Кнопка Продолжить инициирует процесс смены пин-кода. В случае успешной смены новый пин-код сразу используется для доступа к операции.

Примечание: Процесс смены пин-кода доступен, если при использовании сервиса DSS допускается применение пин-кодов для сертификатов.
