Предназначена для хранения индивидуальных настроек подключения, привязанных к сервису DSS.

Информация учетной записи позволяет хранить данные, необходимые для авторизации пользователя и настроек вторичного подтверждения. Техническая информация о подключении к сервису DSS хранится в данных связанного с этой учетной записью элемента сервера DSS.

Форма создания учетной записи DSS содержит вкладки: Главное и Дополнительно. Доступны команды Проверить подключение, Отчеты и Обсуждение.

Главное

  • В поле Сервер указывается элемент справочника «Серверы DSS», к которому привязывается учетная запись (выбирается из выпадающего списка).
  • В поле Логин указывается уникальное имя учетной записи, выданное провайдером пользователю при регистрации.
  • В поле Пароль можно опционально указать пароль при первичной авторизации. Введенный пароль сохраняется в настройках текущего пользователя.
  • В поле Первичная авторизация необходимо выбрать способ авторизации пользователя, который допускается при работе с сервисом. Доступны следующие способы:
    • Логин и пароль — стандартная авторизация с использованием учётной записи.
    • Логин и пароль с дополнительным подтверждением — двухфакторная авторизация.
    • Сертификат авторизации — авторизация с использованием сертификата электронной подписи.
    • Авторизация через Web-форму — авторизация через веб-интерфейс.
    • Сервисный клиент — авторизация для сервисных учётных записей.
  • В поле Подтверждение операций задается способ, который будет автоматически заполняться при процедуре подтверждения операций подписи, расшифровки и прочих. Доступны следующие способы подтверждения:
    • Мобильное приложение myDSS — подтверждение через мобильное приложение myDSS.
    • Электронная почта — подтверждение через электронную почту.
    • SMS — подтверждение через SMS-сообщение.
    • Мобильное приложение AirKey DSS — подтверждение через мобильное приложение AirKey DSS.
    • Мобильное приложение myDSS 2.0 или другое — подтверждение через другие мобильные приложения.

Дополнительно

  • Поле Автор — указывается пользователь, создавший учетную запись (например, Администратор). Заполняется автоматически, может быть изменено.
  • Поле Комментарий — содержит произвольную текстовую информацию об учетной записи DSS.
