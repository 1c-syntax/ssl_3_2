Предназначена для вторичного подтверждения операций в сервисе DSS с помощью мобильного приложения.

Для использования этого способа подтверждения на мобильное устройство на платформах iOS или Android должно быть установлено мобильное приложение myDSS или AirKey DSS. Дополнительно мобильное устройство с установленным приложением должно быть зарегистрировано в сервисе DSS.

Порядок работы

  • В поле сертификат указывается информация о сертификате, используемом при операции.
  • В поле способ подтверждения можно изменить текущий способ на любой доступный в списке выбора.
  • В поле документы указывается список документов, с которыми проводится операция. Доступно только для операции Создание электронной подписи.
  • Процесс подтверждения сопровождается анимацией, приложение периодически опрашивает статус подтверждения в сервисе, и в случае успеха форма автоматически закрывается.
  • В нижней части выводится время, оставшееся до окончания процедуры подтверждения операции.
