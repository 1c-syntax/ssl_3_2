Предназначена для удаления пользовательских настроек.

Иногда требуется удалить пользовательские настройки, например, если из-за этих неправильных настроек работа в приложении стала невозможной. Очистить можно все настройки, в том числе и личные варианты отчетов.

Команда для очистки настроек пользователей находится в разделе Администрирование - Настройки пользователей и прав.

Форма Очистка настроек

Форма очистки настроек содержит следующие группы параметров:

Кому очистить

С помощью переключателя Кому очистить выберите пользователей, которым необходимо очистить настройки:

  • Выбранным пользователям — очистка настроек только у указанных пользователей.
    • Перейдите по ссылке Выбрать для выбора пользователей.
    • Выберите список Пользователи (Внешние пользователи).
    • В списке Выбор пользователей включите соответствующие флажки, нажмите кнопку Выбрать.
    • После завершения выбора отображается список выбранных пользователей (например, Администратор с возможностью удаления (×) каждого).
  • Всем пользователям — очистка настроек у всех пользователей системы. В этом случае можно очистить только Все настройки.

Что очистить

С помощью переключателя Что очистить выберите, какие настройки очищать:

  • Все настройки — полная очистка всех пользовательских настроек. При выборе нескольких пользователей или всех пользователей возможна очистка только всех настроек каждого пользователя.
  • Устаревшие — очистка только устаревших настроек, которые более не используются в приложении.
  • Выбранные — очистка только выбранных вручную настроек.
    • Если в поле Кому очистить выбран один пользователь, то становится доступна возможность выбора отдельных настроек.
    • Перейдите по ссылке Выбрать настройки.
    • В открывшемся окне Выбор настроек пользователя отметьте флажками настройки для очистки.
    • После завершения выбора ссылка принимает значение: наименование одной настройки пользователя или количество выбранных настроек.

Кнопки формы

  • Очистить и закрыть — выполнить очистку настроек с выбранными параметрами и закрыть форму, вернувшись в приложение.
  • Очистить — выполнить очистку настроек с выбранными параметрами, после чего продолжить работу с формой (оставить форму открытой).
