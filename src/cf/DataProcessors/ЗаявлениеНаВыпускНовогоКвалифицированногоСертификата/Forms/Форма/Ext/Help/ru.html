Предназначена для подготовки заявления на выпуск нового квалифицированного сертификата в удостоверяющий центр 1С.

Заполните необходимые поля. Рекомендуется выбирать данные из списка, это значительно уменьшает вероятность ошибок и повышает скорость заполнения. Приложение проверяет правильность заполнения реквизитов, если они были неправильно заполнены, выводится сообщение об ошибке.

Способы оформления заявления

В зависимости от выбранного способа оформления, форма заявления может отличаться набором полей и действий. Подробное описание каждого способа приведено ниже.

1. Бумажное заявление (офлайн-оформление)

Данный способ оформления используется, если заявление распечатывается и передаётся в обслуживающую организацию в бумажном виде.

  • Оформить - выберите значение В бумажном виде.
  • Физическое лицо - выберите владельца сертификата из списка или заполните поля вручную (ФИО, паспортные данные, СНИЛС).
  • Тариф - выберите тариф 1С:Подписи (например, 1С:Подпись.БАЗОВЫЙ (1 050 ₽)).
  • Обслуживающая организация - выберите из списка организацию, через которую оформляется сертификат. После выбора автоматически заполняются поля Наименование, ИНН партнера, КПП партнера.
  • Создать ключ электронной подписи и запрос на сертификат с помощью - выберите криптопровайдер из списка установленных на компьютере (например, КриптоПро CSP (ГОСТ 2012/256)).
  • Включить лицензию КриптоПро CSP - опциональный флажок для приобретения лицензии на криптопровайдер.
  • Печать заявления: текст заявления - ссылка для предварительного просмотра и печати заявления.
  • Подготовьте комплект документов и передайте представителю обслуживающей организации.
  • При первичной идентификации потребуется фото заявителя с паспортом.
  • Нажмите кнопку Отправить заявление.

2. Электронное заявление (онлайн-оформление)

Данный способ используется для отправки заявления в электронном виде, подписанного сертификатом электронной подписи. Заявление подписывается и отправляется непосредственно из приложения.

  • Оформить - выберите значение В электронном виде.
  • для продления сертификата - доступно при выборе электронного оформления. Выберите сертификат, которым будет подписано заявление (для продления действующего сертификата).
  • Физическое лицо - выберите владельца сертификата из списка или заполните поля вручную.
  • Тариф - выберите тариф 1С:Подписи (например, 1С:Подпись.БАЗОВЫЙ (1 050 ₽)).
  • Создать ключ электронной подписи и запрос на сертификат с помощью - выберите криптопровайдер из списка установленных на компьютере (например, КриптоПро CSP (ГОСТ 2012/256)).
  • Включить лицензию КриптоПро CSP - опциональный флажок для приобретения лицензии на криптопровайдер.
  • Паспорт (разворот с фото): выбрать файл - прикрепите скан-копию разворота паспорта с фотографией владельца.
  • СНИЛС - при необходимости прикрепите скан СНИЛС.
Создание ключа электронной подписи
  • Для создания ключа используется выбранное приложение или токен.
  • Требуется помощь? - ссылка для обращения в службу поддержки.
  • Нажимая кнопку Подписать и отправить заявление, вы принимаете условия соглашения о присоединении к Порядку удостоверяющего центра.
  • Нажмите кнопку Подписать и отправить заявление.
  • Заявление будет подписано выбранным сертификатом и отправлено в удостоверяющий центр.

Общая информация для обоих способов

Тарифы 1С:Подписи

Доступны следующие тарифы:

  • 1С:Подпись.БАЗОВЫЙ (1 050 ₽) - подходит для ЭДО с контрагентами, сдачи отчетности, работы с Гос. Порталами.
  • 1С:Подпись.ЕГАИС (2 200 ₽) - для работы в системе ЕГАИС.
  • 1С:Подпись.Торги.Фабрикант (5 000 ₽) - для участия в торгах на площадке Фабрикант.
  • 1С:Подпись.Торги.В2В (4 500 ₽) - для участия в торгах в сегменте B2B.
  • 1С:Подпись.Торги.В2В+Фабрикант (8 500 ₽) - комбинированный тариф для участия в торгах на обеих площадках.

Подробная информация о тарифах см. на сайте. Окончательная стоимость может отличаться в зависимости от услуг, предоставляемых Партнером 1С.

Создание ключа электронной подписи и запроса на сертификат

  • Для создания запроса на сертификат используется приложение электронной подписи и шифрования КриптоПро CSP или ViPNet CSP или активный ключевой носитель (Рутокен или JaCarta).
  • По вопросам работы приложения обратитесь к его документации или воспользуйтесь дополнительной инструкцией на сайте 1С.
  • Для работы с Рутокеном: скачайте и установите библиотеку с сайта производителя и вставьте токен в компьютер.
  • Для работы с JaCarta: скачайте и установите библиотеку с сайта производителя и вставьте токен в компьютер.
  • Ключ электронной подписи - это секретная информация, которая сохраняется на компьютере, флешку, устройстве или другой носитель информации и используется в дальнейшем для создания электронных подписей.
  • Запрос на сертификат - это структурированные данные, содержащие информацию о владельце и открытый ключ, которые отправляются в удостоверяющий центр.

Соглашение

  • Нажимая кнопку отправки заявления, вы принимаете условия соглашения о присоединении к регламенту удостоверяющего центра (УЦ).
  • По гиперссылке можно перейти к просмотру информации об УЦ.

Сохранение заявления

  • Заявление сохраняется автоматически на стадии подготовки и хранится в списке сертификатов. В любой момент к нему можно вернуться и продолжить работу.

Ожидание обработки заявления

  • Для проверки состояния заявления нажмите кнопку Обновить состояние.

Выгрузка сертификата

С помощью подменю Техническая информация можно:

  • Выгрузить Запрос на сертификат;
  • Выгрузить Корневой сертификат;
  • Выгрузить Сертификат - это может потребоваться, если автоматически загрузить сертификат не удалось.
