Предназначена для просмотра основных свойств сертификата ключа электронной подписи и шифрования.

Форма содержит следующие вкладки: Основное, Субъект, Издатель, Путь сертификации, Списки отзыва, Внутреннее содержание.

Основные сведения о сертификате 

  • Кому выдан - личные данные владельца сертификата.
  • Кем выдан - данные об Удостоверяющем центре, который выдал сертификат.
  • Срок действия сертификата - дата, до которой действует сертификат.
  • Алгоритм подписи - алгоритм закрытого и открытого ключа.
  • Назначение - виды и коды назначений сертификата:
    • Подписание - флажок включен, если сертификат предназначен для подписания. Отображаются все коды назначения (OID), например: 1.3.6.1.5.5.7.3.2, 1.3.6.1.5.5.7.3.4.
    • Шифрование - флажок включен, если сертификат предназначен для шифрования.
  • Алгоритм открытого и закрытого ключа (асимметричный) для: - создания и проверки подписи, шифрования и расшифровки дополнительного секретного ключа симметричного алгоритма шифрования (которым шифруются и расшифровываются данные).

Путь сертификации

  • Содержит информацию о цепочке сертификатов, которые можно установить в личное хранилище, в хранилище доверенных корневых сертификатов или в найденный контейнер.
  • Пример цепочки сертификатов:
    • Головной удостоверяющий центр, до 07.2027
    • УЦ 1 ИС ГУЦ, до 07.2027
    • ООО "НПЦ "1С" (УЦ 1), до 08.2027
    • Иванов Иван, до 02.2027
  • Кнопка Установить сертификат - позволяет установить выбранный сертификат из цепочки в соответствующее хранилище.

Списки отзыва

  • Содержит ссылки на списки отозванных сертификатов (CRL - Certificate Revocation List).
  • Адреса списков отзыва:
    • http://ca.1c.ru/cdp/1cca1_2016k.crl
    • http://1cbo.1c.ru/cdp/1cca1_2016k.crl
  • Кнопка Установить список отзыва - позволяет загрузить и установить актуальный список отозванных сертификатов.

Внутреннее содержание

Состав и значения свойств, как они указаны в данных сертификата. Для просмотра доступны группы свойств:

  • Общие свойства - основные параметры сертификата.
  • Субъект - детальные свойства владельца (с OID).
  • Издатель - детальные свойства УЦ (с OID).
  • Расширенные свойства - дополнительные параметры сертификата.

Выгрузка сертификата

  • Нажмите Сохранить в файл и укажите папку, для того чтобы сохранить данные сертификата на компьютер.
  • При успешном сохранении отображается сообщение «Сертификат сохранен».

Проверка сертификата

  • Нажмите Проверить, для того чтобы проверить действительность сертификата.
