Предназначена для добавления электронной подписи из файла к элементам некоторых списков информационной базы. Эту возможность можно использовать, например, если подпись в виде файла была получена позже, чем подписанные данные.

Открывается из списка файлов (списка присоединенных файлов объекта), списка Присоединенные файлы по кнопке Электронная подпись и шифрование - Добавить электронную подпись из файла. Также можно найти эту команду в меню Еще карточки файла (карточки присоединенного файла).

Добавление электронной подписи из файла

В форме отображается:

  • Файл – документ, к которому добавляется электронная подпись.
  • Кнопка + Выбрать файлы с компьютера... – для выбора одного или нескольких файлов электронной подписи с устройства.

В табличной части выводятся следующие колонки:

  • Файл электронной подписи – путь к файлу, содержащему электронную подпись. Поддерживается только отсоединенная подпись в формате PKS#7 (расширение .p7s). В подпись обязательно должен быть включен сертификат, которым выполнена подпись. Если сертификат не включен, при проверке подписи и при добавлении из файла возникнет ошибка.
  • Комментарий – сведения, которые поясняют добавляемую электронную подпись.
  • Машиночитаемая доверенность – при необходимости можно прикрепить машиночитаемую доверенность (МЧД).

Если список подписей пуст, отображается сообщение: Список пуст. Необходимо добавить хотя бы одну строку.

Для добавления подписи:

  • Нажмите кнопку + Выбрать файлы с компьютера... или кнопку Добавить в нижней части формы.
  • В открывшемся диалоговом окне укажите путь к файлу подписи на устройстве.
  • При необходимости заполните Комментарий и укажите Машиночитаемую доверенность.

Важно: На данный момент не поддерживается работа с присоединенной подписью в формате PKCS#7.

Подписи файлов сохраняются в приложении, в отличие от самих файлов, которые также могут храниться в томах.

Удаление электронной подписи

  • Нажмите Еще - Удалить для удаления файла электронной подписи из списка.
