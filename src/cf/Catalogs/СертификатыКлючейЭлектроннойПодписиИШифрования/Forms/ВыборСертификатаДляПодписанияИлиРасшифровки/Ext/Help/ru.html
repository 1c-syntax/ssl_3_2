Показывает сертификаты для подписания или расшифровки данных.

Личные сертификаты на компьютере

По умолчанию показываются личные сертификаты. Если список пуст, то на компьютере нет подходящих личных сертификатов.
Включите флажок Показать все сертификаты для отображения всех доступных сертификатов (не только личных).
Для подписания данных используются только личные сертификаты.

Ссылки и элементы управления

  • Инструкции... - открывает справочную информацию по работе с сертификатами.
  • Показать все сертификаты - флажок для отображения всех сертификатов, установленных на компьютере.
  • Поиск - поле для быстрого поиска нужного сертификата в списке.

Список сертификатов

В списке отображаются доступные сертификаты с их представлением.

Если сертификаты найдены, выберите нужный, нажмите кнопку Далее для заполнения сведений о сертификате.

Добавление (выбор) сертификата

  • Данные сертификата заполняются автоматически из выбранного сертификата:
    • Кому выдан - наименование организации или владельца сертификата.
    • Кем выдан - информация об удостоверяющем центре, выдавшем сертификат.
    • Действителен до - дата окончания срока действия закрытого ключа.
    • Назначение - для каких целей может использоваться сертификат.
  • Кнопка Показать сертификат позволяет просмотреть подробную информацию о выбранном сертификате.
  • Заполните недостающие поля:
    • Представление - краткое наименование сертификата для отображения в списках. Заполняется автоматически, может быть отредактировано.
    • Организация - выберите организацию из списка, от имени которой будет использоваться сертификат.
    • Пользователь - выберите пользователя из списка, который будет связан с сертификатом.
    • Администратор - признак того, что сертификат принадлежит администратору.
    • Физическое лицо - флажок, указывающий, что сертификат принадлежит физическому лицу (а не организации).
  • При добавлении сертификата для подписания или расшифровки данных необходимо ввести Пароль:
    • Включите флажок Вводить пароль в приложении электронной подписи, если пароль запрашивается через криптопровайдер.
    • Поле Пароль - для ввода пароля доступа к закрытому ключу сертификата.
    • Запомнить на время сеанса - флажок, позволяющий не вводить пароль повторно при каждом использовании сертификата в текущем сеансе работы.
  • Для добавления (выбора) сертификата нажмите кнопку Добавить. Для возврата к предыдущему шагу используйте кнопку < Назад.
