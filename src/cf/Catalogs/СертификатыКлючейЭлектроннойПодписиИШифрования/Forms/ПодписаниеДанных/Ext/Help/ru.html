Предназначена для подписания файлов, электронных документов и других данных.

Электронная подпись - реквизит электронного документа, с помощью которого можно удостовериться в неизменности электронного документа с момента его подписи. Контроль неизменности электронного документа осуществляется в результате проверки соответствия электронной подписи и документа, а также проверки действительности сертификата. Контроль неизменности электронного документа можно выполнить в любой момент времени.

Подписываемый файл

С помощью ссылки в верхней части окна можно просмотреть объект, который будет подписан. Ссылка принимает значение наименования объекта.

Выбор способа подписания

С помощью переключателя выберите один из режимов подписания:

  • В этом приложении - подписание выполняется непосредственно в приложении с использованием установленного сертификата и криптопровайдера.
  • В мобильном приложении "Моя подпись" от ФНС - документы отправляются для подписания в мобильное приложение. Необходимо будет дождаться получения результатов подписания. Документы будут отправлены подписанту в приложение "Моя подпись" от ФНС.

Подписание данных в этом приложении

  • Выберите Тип подписи:
    • Квалифицированная базовая подпись (CAdES-BES) - действительна до окончания срока действия сертификата подписанта (обычно в течение 1 года).
    • Подпись с меткой доверенного времени (CAdES-T) - действует после окончания срока действия сертификата подписанта.
    • Архивная подпись (CAdES-A) - содержит полный набор доказательств подлинности, в том числе цепочку сертификатов, и автоматически продлевается.
  • Если Сертификат не выбран - выберите его из списка. Если при следующем открытии сертификат будет среди установленных на компьютере, повторный выбор не потребуется.
  • При выборе из выпадающего списка будут показаны только сертификаты, у которых поле Пользователи не заполнено или совпадает с текущим пользователем сеанса, а поле Приложение заполнено. Если при открытии окна Подписание был указан отбор по организации, то в выпадающем списке не будет сертификатов, у которых поле Организация не совпадает с организацией, указанной в отборе. Если при открытии окна Подписание был указан конкретный список сертификатов, то будет показан только этот список.
  • При выборе из списка личных сертификатов (установленных на компьютере и на сервере) путем нажатия Показать все, показываются все сертификаты без учета полей Пользователь и Приложение. Если при открытии окна Подписание был указан отбор по организации, то в списке не будет сертификатов, у которых поле Организация не совпадает с организацией, указанной в отборе. Но будут показаны все сертификаты, которых еще нет в списке (то есть те, которые есть только в хранилище сертификатов операционной системы компьютера или сервера).
  • В поле Пароль введите пароль к закрытому ключу (указанный при установке или создании сертификата) или ПИН-код, если местом хранения сертификата является сервис DSS.
  • Включите флажок Запомнить на время сеанса, для того чтобы не вводить пароль (ПИН-код для сервиса DSS) повторно в течение текущего сеанса работы.
  • Также файл можно подписать с помощью МЧД, для этого включите флажок По доверенности и выберите соответствующую доверенность из списка.
  • В некоторых случаях можно ввести Комментарий к подписи - дополнительную информацию о подписи.
  • Для выполнения подписи нажмите Подписать.
  • Данные будут подписаны с использованием указанного сертификата.
  • Созданная электронная подпись хранится в приложении. Подписанный объект становится недоступным для редактирования и отображается в списках со значком .

Подписание данных в мобильном приложении "Моя подпись" от ФНС

  • С помощью переключателя выберите режим В мобильном приложении "Моя подпись" от ФНС. Режим предназначен для подписания документов непосредственно в мобильном приложении.
  • Тип подписи заполняется автоматически.
  • Выберите Подписанта - пользователя, которому будут отправлены документы для подписания.
  • Документы будут отправлены подписанту в приложение "Моя подпись" от ФНС. Необходимо будет дождаться получения результатов подписания.
  • Также файл можно подписать с помощью МЧД, для этого включите флажок По доверенности и выберите соответствующую доверенность из списка.
  • В некоторых случаях можно ввести Комментарий к подписи - дополнительную информацию о подписи.
  • Для выполнения подписи нажмите Подписать.
  • Документы будут направлены в систему для последующего подписания через мобильное приложение.
  • После отправки документов подписанту появится уведомление о том, что документы отправлены. Для их подписания нужно воспользоваться приложением "Моя подпись" от ФНС.
  • После подписания документов следует нажать кнопку Документы подписаны, для того чтобы запустить процесс получения подписи из сервиса. Важно учитывать, что при отмене операции или закрытии окна запрос на подписание будет автоматически аннулирован.
  • Созданная электронная подпись хранится в приложении. Подписанный объект становится недоступным для редактирования и отображается в списках со значком .
