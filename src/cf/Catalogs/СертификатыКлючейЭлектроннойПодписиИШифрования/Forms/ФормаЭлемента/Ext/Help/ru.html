Сведения о сертификате электронной подписи.

Заголовок карточки сертификата

  • В верхней части карточки отображается наименование сертификата с указанием срока действия.
  • Если сертификат просрочен, выводится предупреждение Сертификат просрочен.

Команды и действия

  • Перевыпустить... - позволяет выпустить новый сертификат на смену текущему (например, при истечении срока действия).
  • Проверить... - выполняет проверку действительности сертификата.
  • Обсуждение - переход к обсуждению сертификата.
  • Показать сертификат - кнопка для просмотра подробной информации о сертификате.

Основные сведения о сертификате

Приложение автоматически выводит данные о сертификате:

  • Кому выдан - личные данные владельца сертификата.
  • Кем выдан - данные об УЦ, который выдал сертификат.
  • Действителен до - минимальная дата из срока действия сертификата и срока действия закрытого ключа. Создать подпись можно до этой даты. Используется при проверке подписи, если подпись не содержит метки времени.
  • Назначение - виды и коды назначений сертификата.

Представление

  • Представление - краткое наименование сертификата для отображения в списках. Заполняется автоматически, может быть отредактировано.

Сведения о владельце сертификата

  • Данные владельца подписи (заполняются автоматически) в поле Кому выдан:
    • Фамилия, Имя, Отчество;
    • Фирма;
    • Должность;
  • Физическое лицо - выберите из списка физическое лицо или нажмите Подобрать автоматически (физическое лицо подберется по наименованию из поля сертификата Кому выдан). Поле может быть заполнено автоматически.
  • Организация - выберите из списка организацию, которой выдан сертификат.
  • Используют - заполняется автоматически при добавлении сертификата. Редактировать можно в карточке сертификата. Выберите из списка пользователей. В карточке сертификата поле предназначено для указания списка пользователей, у которых данный сертификат будет отображаться в окнах подписания и шифрования данных.
  • Добавил - выберите пользователя, который добавил сертификат в список (например, Администратор).

Настройки закрытого ключа (для создания электронных подписей или расшифровки данных)

При необходимости можно хранить пароль не в приложении 1С:Предприятие, а в приложении электронной подписи.
    • Приложение - выберите приложение или сервис для электронной подписи и шифрования, в котором будет храниться пароль. Доступные варианты:
      • По умолчанию - используется приложение, выбранное в настройках электронной подписи и шифрования;
      • Конкретный криптопровайдер (КриптоПро CSP, ViPNet CSP и др.);
      • Аппаратный токен (Рутокен, JaCarta и др.).
    • Вводить пароль в приложении электронной подписи - включите флажок, если необходимо вводить и хранить пароль в приложении электронной подписи (а не в 1С:Предприятие).

Проверка сертификата

  • Нажмите Проверить, для того чтобы произвести проверку сертификата. Проверка занимает некоторое время, проводится по нескольким параметрам. Если сертификат недействителен, то приложение выводит подробное сообщение о возможных причинах его недействительности.

Просмотр данных сертификата

  • Нажмите , для того чтобы просмотреть все свойства сертификата.

Просмотр заявления

  • Нажмите , для того чтобы просмотреть заявление, по которому был получен сертификат.

Выгрузка в файл

  • Нажмите Сохранить в файл, укажите путь к папке для сохранения в файл.

Автозаполняемые реквизиты

  • Установите соответствующий флажок меню Еще, для того чтобы Показать автозаполняемые реквизиты. В этом случае показываются данные владельца подписи, которые заполняются автоматически.

Отозванные сертификаты

  • Включите флажок Еще - Сертификат отозван. Действие необратимо.
